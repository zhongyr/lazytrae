# ulw-research

Read [host conventions](../../HOST.md). Frame the question and evidence needed. Search repository sources first for local behavior and authoritative external sources for current public claims. Use only available research tools.

Track source URLs, versions/dates, comparable conditions and uncertainty. Separate measured results from anecdotes and inference. Never infer a same-model benchmark from a leaderboard that changes both the model and harness. Delegate independent research questions only if allowed. Deliver a clear answer with supporting sources and limits.
