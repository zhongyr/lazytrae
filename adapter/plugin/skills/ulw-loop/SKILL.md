# ulw-loop

Read [host conventions](../../HOST.md), then [the loop procedure](references/workflow.md). Use the bundled Node runtime and a stable session ID on every command. Never invoke an external OmO installer.

Define concrete acceptance criteria before coding. Keep the live plan aligned with the ledger. After compaction read the brief, goals, ledger and status before resuming. Do not recreate an existing plan or overwrite evidence.

Complete criteria only with observed results. A final checkpoint requires real nonempty artifacts, review and outcome coverage. Missing QA, blocked checks, or stale evidence are incomplete work. Do not fabricate host goal snapshots, evidence or approvals.
