# ultrawork

Read [host conventions](../../HOST.md). State the requested outcome and acceptance criteria. For a small task, implement and verify directly. For work needing recovery, multiple milestones or a durable audit, follow [ulw-loop](../ulw-loop/SKILL.md). Do not force a ledger onto a one-line task.

Explore the relevant implementation before editing. Use a short live plan for substantial work. Delegate independent tasks only when the host allows it; give each worker a scope, deliverable and verification requirement. Keep useful local work moving while children run.

Preserve the user's budget and scope. A workflow request does not authorize publishing, new subscriptions, a host goal, or changing host settings. Finish all already-authorized delivery work. Cite the actual checks and evidence, and report limitations plainly. A user's pause or cancellation takes effect immediately.
